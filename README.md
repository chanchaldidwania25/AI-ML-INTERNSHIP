# 📊 SwiftKart E-Commerce Analytics Practicum
## 📊 Project Overview
This repository contains my internship practicum on **E‑Commerce Customer Behavior & Delivery Analytics** for **SwiftKart**, a high‑growth Indian e‑commerce platform.[SwiftKart_Analytics Practicum.pdf](https://github.com/chanchaldidwania25/AI-ML-INTERNSHIP/blob/main/ecommerce_customer_behavior_and_delivery_analytics%20(1).pdf)

The project focuses on analyzing **unit economics, logistics bottlenecks, and discount elasticity**.

This **foundational analytics capstone** demonstrates end‑to‑end data cleaning, vectorized operations, business aggregations, and storytelling through visualizations addressing SwiftKart’s operational challenges.  

## 🛒 Business Context

SwiftKart faced three critical challenges:  
- **Surging Return Rates** → High reverse logistics costs and margin erosion  
- **Fulfillment Friction** → Delivery delays leading to poor ratings and cancellations  
- **Margin Dilution** → Heavy reliance on discounts without clarity on customer stickiness

My role as a Junior Data Analyst was to **ingest raw transactional data, clean anomalies, engineer KPIs, and generate insights** to guide logistics managers and marketing directors.

## 📂 Dataset
The dataset ([Ecommerce_Orders_For_Cleaning.csv](https://github.com/chanchaldidwania25/AI-ML-INTERNSHIP/blob/main/Ecommerce_Orders_For_Cleaning.csv)) simulates **1,000+ customer transactions** with attributes including Order & Customer IDs, Product Category, Payment Method, Order Value & Discounts, Delivery Days, Customer Ratings, Return Status, and City Tier.

👉 The dataset included **real‑world anomalies**: duplicates, missing values, inconsistent casing, and skewed distributions — all of which were systematically cleaned.
